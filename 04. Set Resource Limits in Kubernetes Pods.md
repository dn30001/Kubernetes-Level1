# 04. Set Resource Limits in Kubernetes Pods

The Nautilus DevOps team has noticed performance issues in some Kubernetes-hosted applications due to resource constraints. To address this, they plan to set limits on resource utilization. Here are the details:


Create a pod named `httpd-pod` with a container named `httpd-container`. Use the `httpd` image with the `latest` tag (specify as `httpd:latest`). Configure the following container-level resource requests and limits for the container:

<b>Requests:</b> Memory: `15Mi`, CPU: `100m`

<b>Limits:</b> Memory: `20Mi`, CPU: `100m`

<b>Note:</b> The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.

#

1. Create and enter the `httpd-pod.yaml` file.
```
vi httpd-pod.yaml
```
<br>
<br>

2. Enter the configuration contents according to the instructions of the task.
````
apiVersion: v1
kind: Pod
metadata:
  name: httpd-pod
spec:
  containers:
    - name: httpd-container
      image: httpd:latest
      resources:
        requests:
          memory: "15Mi"
          cpu: "100m"
        limits:
          memory: "20Mi"
          cpu: "100m"
````
<br>
Save and exit.
<br>
<br>

3. Apply the configuration.
```
kubectl apply -f httpd-pod.yaml
```
<br>
<br>

4. Verify the Pod
```
kubectl get pods
```
<br>
<br>

5. Verify the Resource Requests and Limits.
```
kubectl describe pod httpd-pod
```

#

This configuration meets all the specified requirements:
- Pod name: `httpd-pod`
- Container name: `httpd-container`
- Image: `httpd:latest`
- Requests: CPU `100m`, Memory `15Mi`
- Limits: CPU `100m`, Memory `20Mi`
