# 09. Create Countdown Job in Kubernetes

The Nautilus DevOps team is crafting jobs in the Kubernetes cluster. While they're developing actual scripts/commands, they're currently setting up templates and testing jobs with dummy commands. Please create a job template as per details given below:


1. Create a job named `countdown-datacenter`.

2. The spec template should be named `countdown-datacenter` (under metadata), and the container should be named `container-countdown-datacenter`

3. Utilize image `ubuntu` with latest tag (ensure to specify as `ubuntu:latest`), and set the restart policy to `Never`.

4. Execute the command `sleep 5`

**Note:** The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.

#

1. Create and enter the countdown-datacenter.yaml file.
```
vi countdown-datacenter.yaml
```
<br>

2. Enter the configuration contents according to the instructions of the task:
```
apiVersion: batch/v1
kind: Job
metadata:
  name: countdown-datacenter
spec:
  template:
    metadata:
      name: countdown-datacenter
    spec:
      containers:
        - name: container-countdown-datacenter
          image: ubuntu:latest
          command:
            - "sleep"
            - "5"
      restartPolicy: Never
```
Save and exit
<br>
<br>

3. Apply the configuration
```
kubectl apply -f countdown-datacenter.yaml
```
<br>

4. Verify
```
kubectl get jobs
kubectl get pods
```
