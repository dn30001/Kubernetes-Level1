# 08. Schedule Cronjobs in Kubernetes

The Nautilus DevOps team is setting up recurring tasks on different schedules. Currently, they're developing scripts to be executed periodically. To kickstart the process, they're creating cron jobs in the Kubernetes cluster with placeholder commands. Follow the instructions below:


1. Create a cronjob named `nautilus.`

2. Set Its schedule to something like `*/12 * * * *`. You can set any schedule for now.

3. Name the container `cron-nautilus`.

4. Utilize the `httpd` image with latest tag (specify as `httpd:latest`).

5. Execute the dummy command `echo Welcome to xfusioncorp!`.

6. Ensure the restart policy is `OnFailure`.


**Note:** The `kubectl` utility on the `jump-hos`t has been configured to work with the Kubernetes cluster.

#

1. Create and enter the `nautilus-cronjob.yaml` file.
```
vi nautilus-cronjob.yaml
```
<br>
<br>

2. Enter the configuration contents according to the instructions of the task:
````
apiVersion: batch/v1
kind: CronJob
metadata:
  name: nautilus
spec:
  schedule: "*/12 * * * *"
  jobTemplate:
    spec:
      template:
        spec:
          restartPolicy: OnFailure
          containers:
            - name: cron-nautilus
              image: httpd:latest
              command:
                - /bin/sh
                - -c
                - echo Welcome to xfusioncorp!
````
<br>

Save and Exit
<br><br>

3. Apply the configuration.
```
kubectl apply -f nautilus-cronjob.yaml
```
<br><br> 

4. Verify the CronJob.
```
kubectl get cronjob nautilus
```
<br><br>

5. Verify the configuration.
```
kubectl describe cronjob nautilus
```
<br><br>

6. Test the Job manually.
```
kubectl create job --from=cronjob/nautilus nautilus-test
```
<br><br>

7. Then check job:
```
kubectl get jobs
```
<br><br>

8. And view the output:
```
kubectl logs job/nautilus-test
```
