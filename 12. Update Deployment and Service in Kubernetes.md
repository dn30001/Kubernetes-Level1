# 12. Update Deployment and Service in Kubernetes

An application deployed on the Kubernetes cluster requires an update with new features developed by the Nautilus application development team. The existing setup includes a deployment named `nginx-deployment` and a service named `nginx-service`. Below are the necessary changes to be implemented without deleting the deployment and service:


1.) Modify the service nodeport from `30008` to `32165`

2.) Change the replicas count from `1` to `5`

3.) Update the image from `nginx:1.17` to `nginx:latest`

**Note:** The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.

#

1. Check the existing Deployment and Service
```
kubectl get deployment nginx-deployment
kubectl get service nginx-service
```
<br>

2. Check the current Pods
```
kubectl get pods
```
<br>

3. Change the Service NodePort. The existing Service has NodePort 30008. We need to change it to 32165.
```
kubectl edit service nginx-service
```
<br>

Look for:
```
ports:
- nodePort: 32165
```
<br>

Change to:
<br>
`nodePort: 32165`
<br>

Save and Exit
<br>
<br>

4. Verify the change
```
kubectl get service nginx-service
```
<br>

5. Change the Deployment replicas from 1 to 5
```
kubectl scale deployment nginx-deployment --replicas=5
```
<br>

6. Verify the change
```
kubectl get deployment nginx-deployment
```
<br>

7. Change the image to `nginx:latest`
```
kubectl set image deployment/nginx-deployment nginx-container=nginx:latest
```
<br>

8. Watch the rolling update
```
kubectl rollout status deployment/nginx-deployment
```
<br>

If successful, you'll get:
<br>
`deployment "nginx-deployment" successfully rolled out`
<br>
<br>

9. Verify the image
```
kubectl get deployment nginx-deployment -o wide
```
<br>

10. Verify all 5 Pods
```
kubectl get pods
```
