# 05. Execute Rolling Updates in Kubernetes


An application currently running on the Kubernetes cluster employs the nginx web server. The Nautilus application development team has introduced some recent changes that need deployment. They've crafted an image `nginx:1.18` with the latest updates.


Execute a rolling update for this application, integrating the `nginx:1.18` image. The deployment is named `nginx-deployment`.

Ensure all pods are operational post-update.

Note: The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.

#

1. Verify the deployment already exists.
```
k get deploy
```
<br>
<br>

2. Verify the pods.
```
k get pods
```
<br>
<br>

3. Verify the nginx version of the current deployment.
```
k describe deploy nginx-deployment
```
<br>
Check for the image version.

`Image:         nginx:1.16`
<br>
<br>

4. Run the image update command.
```
kubectl set image deployment/nginx-deployment nginx-container=nginx:1.18
```
<br>
<br>

5. Verify the deployment.
```
k get deploy
```
<br>
<br>

6. Verify the nginx version of the current deployment.
```
k describe deploy nginx-deployment
```
<br>
Check for the image version.

`Image:         nginx:1.18`
