# 10. Set Up Time Check Pod in Kubernetes

The Nautilus DevOps team needs a time check pod created in a specific Kubernetes namespace for logging purposes. Initially, it's for testing, but it may be integrated into an existing cluster later. Here's what's required:


1. Create a pod called `time-check` in the `datacenter` namespace. The pod should contain a container named `time-check`, utilizing the `busybox` image with the `lates`t tag (specify as `busybox:latest`).

2. Create a config map named `time-config` with the data `TIME_FREQ=3` in the same namespace.

3. Configure the `time-check` container to execute the command: `while true; do date; sleep $TIME_FREQ;done`. Ensure the result is written `/opt/data/time/time-check.log`. Also, add an environmental variable `TIME_FREQ` in the container, fetching its value from the config map `TIME_FREQ` key.

4. Create a volume `log-volume` and mount it at `/opt/data/time` within the container.

**Note:** The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.

#

1. Create and enter the `time-config.yaml` file.
```
vi time-config.yaml
```
<br>

2. Enter the configuration contents according to the instructions of the task:
```
apiVersion: v1
kind: ConfigMap
metadata:
  name: time-config
  namespace: datacenter
data:
  TIME_FREQ: "3"
```
<br>
Save and exit
<br>
<br>

3. Create and enter the `time-check.yaml` file.
```
vi time-check.yaml
```
<br>

4. Enter the configuration contents according to the instructions of the task:
```
apiVersion: v1
kind: Pod
metadata:
  name: time-check
  namespace: datacenter
spec:
  containers:
    - name: time-check
      image: busybox:latest
      command:
        - /bin/sh
        - -c
        - |
          while true; do
            date >> /opt/data/time/time-check.log
            sleep $TIME_FREQ
          done
      env:
        - name: TIME_FREQ
          valueFrom:
            configMapKeyRef:
              name: time-config
              key: TIME_FREQ
      volumeMounts:
        - name: log-volume
          mountPath: /opt/data/time
  volumes:
    - name: log-volume
      emptyDir: {}
```
<br>
Save and exit
<br>
<br>

5. Apply the namespace
```
kubectl create namespace datacenter
```
<br>

6. Apply the `time-check.yaml` configuration.
```
kubectl apply -f time-check.yaml
```
<br>

7. Create the ConfigMap directly.
```
kubectl create configmap time-config \
  --from-literal=TIME_FREQ=3 \
  -n datacenter
```
<br>

8. Verify
```
kubectl get pod time-check -n datacenter
kubectl get configmap time-config -n datacenter
```
<br>

9. Check the generated log:
```
kubectl exec -n datacenter time-check -- cat /opt/data/time/time-check.log
```
