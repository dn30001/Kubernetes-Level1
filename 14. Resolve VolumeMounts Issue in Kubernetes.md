# 14. Resolve VolumeMounts Issue in Kubernetes

We encountered an issue with our Nginx and PHP-FPM setup on the Kubernetes cluster this morning, which halted its functionality. Investigate and rectify the issue:



The pod name is `nginx-phpfpm` and configmap name is `nginx-config`. Identify and fix the problem.


Once resolved, copy `/home/thor/index.php` file from the `jump host` to the `nginx-container` within the nginx document root. After this, you should be able to access the `website` using Website button on the top bar.


**Note:** The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.

#

1. Check status of pod.
```
k get pods
```
<br>

2. Check configmaps.
```
k get configmaps
```
<br>

3. Get status of `nginx-phpfpm` pod.
```
k describe pod nginx-phpfpm
```
<br>

4. Check the configmap.
```
k describe configmap nginx-config
```
<br>

5. Check the pod configuration for mistakes.
```
k get pod nginx-phpfpm -o yaml
```
<br>

6. Recreate the configuration yaml file.
```
k get pod nginx-phpfpm -o yaml > pod.yaml
```
<br>

7. Open the recreated configuration yaml file.
```
vi pod.yaml
```
<br>

8. Find all entries with:
```
volumeMounts:
- mounttPath: /usr/share/nginx/html
```
<br>

Change lines to:
```
- mounttPath: /var/www/html
```
<br>

Save and exit.
<br>
<br>

9. Delete the nginx-phpfpm pod.
```
k delete pod nginx-phpfpm
```
<br>

10. Apply the new configuration.
```
k apply -f pod.yaml
```
<br>

11. Check status of new `nginx-phpfpm` pod.
```
k get pods
```
<br>

12. Copy `/home/thor/index.php` file from the jump host to the `nginx-container` within the nginx document root.
```
k cp /home/thor/index.php nginx-phpfpm:/var/www/html/index.php -c nginx-container
```
<br>

13. Run the Execute command:
```
kubectl exec -it nginx-phpfpm -c nginx-container -- ls /var/www/html
```
<br>

14. Run Cat command to check.
```
kubectl exec -it nginx-phpfpm -c nginx-container -- cat /var/www/html/index.php
```
<br>

15. Click on the **Website** icon.
