# 7. Deploy ReplicaSet in Kubernetes Cluster

The Nautilus DevOps team is gearing up to deploy applications on a Kubernetes cluster for migration purposes. A team member has been tasked with creating a ReplicaSet outlined below:

1. Create a ReplicaSet using `nginx` image with `latest` tag (ensure to specify as `nginx:latest`) and name it `nginx-replicaset`.

2. Apply labels: `app` as `nginx_app`, type as `front-end`.

3. Name the container `nginx-container`. Ensure the replica count is `4`.
<br>

**Note:** The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.

#
<br>

1. Create and enter the `httpd-pod.yaml` file.
```
vi nginx-replicaset.yaml
```
<br>
<br>

2. Enter the configuration contents according to the instructions of the task:
````
apiVersion: apps/v1
kind: ReplicaSet
metadata:
  name: nginx-replicaset
  labels:
    app: nginx_app
    type: front-end
spec:
  replicas: 4
  selector:
    matchLabels:
      app: nginx_app
      type: front-end
  template:
    metadata:
      labels:
        app: nginx_app
        type: front-end
    spec:
      containers:
        - name: nginx-container
          image: nginx:latest
````
<br>

Save and exit.
<br>
<br>

3. Apply the configuration.
```
kubectl apply -f nginx-replicaset.yaml
```
<br>
<br>

4. Verify the ReplicaSet.
```
kubectl get replicasets
```
<br>
<br>

5. Verify all 4 Pods
```
kubectl get pods -l app=nginx_app
```
<br>

#

**Key requirements verified:**
- ReplicaSet: `nginx-replicaset`
- Replicas: `4`
- Image: `nginx:latest`
- Container: `nginx-container`
- Labels:
  - app: `nginx_app`
  - type: `front-end`
