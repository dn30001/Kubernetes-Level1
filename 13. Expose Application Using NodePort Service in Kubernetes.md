# 13 Expose Application Using NodePort Service in Kubernetes

The Nautilus DevOps team has already deployed a `ReplicaSet` to host an application that requires a highly available infrastructure. Your task is to expose the application running in the existing `ReplicaSet` by creating a Kubernetes `NodePort` Service.

Follow the specifications below to create the Service and ensure the application pods are accessible:


1. A ReplicaSet named `httpd-replicaset` is already running in the cluster.

2. The pods managed by the ReplicaSet use the following labels:
Assign labels `app` as `httpd_app`, and type as `front-end`.

3. Create a NodePort Service named `httpd-service` to expose the application.

4. Set the NodePort to `30080`.

5. Expose port `80` of the application.

**Note:** Do not delete or modify the configuration of the deployed `ReplicaSet` application.

#

1. Verify the existing ReplicaSet
```
kubectl get rs
```
<br>

2. Check the ReplicaSet labels
```
kubectl get pods -l app=httpd_app,type=front-end
```
<br>

3. Create the Service YAML
```
vi httpd-service.yaml
```
<br>

4. Enter the configuration contents according to the instructions of the task:
```
apiVersion: v1
kind: Service
metadata:
  name: httpd-service
spec:
  type: NodePort
  selector:
    app: httpd_app
    type: front-end
  ports:
    - port: 80
      targetPort: 80
      nodePort: 30080
```
<br>

5. Apply the configuration
```
kubectl apply -f httpd-service.yaml
```
<br>

6. Verify the Service
```
kubectl get service httpd-service
```
<br>

7. Verify the Service selector
```
kubectl describe service httpd-service
```
<br>

8. Verify the Service has endpoints
```
kubectl get endpoints httpd-service
```
