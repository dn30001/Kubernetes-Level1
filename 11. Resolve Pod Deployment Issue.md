# 11. Resolve Pod Deployment Issue


A junior DevOps team member encountered difficulties deploying a stack on the Kubernetes cluster. The pod fails to start, presenting errors. Let's troubleshoot and rectify the issue promptly.


1. There is a pod named `webserver`, and the container within it is named `nginx-container`, its utilizing the `nginx:latest` image.

2. Additionally, there's a sidecar container named `sidecar-container` using the `ubuntu:latest` image.

Identify and address the issue to ensure the pod is in the running state and the application is accessible.

**Note:** The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.

#

1. Check pod status.
```
k get pods
```
<br> 

2. Check the `webserver` configuration.
```
k describe pod webserver
```
<br>

In the describe configuration, under:
<br>
```
Containers:
  nginx-container:
```
<br>

The error is with:
<br>
`
Image:          nginx:latests
`
<br>
<br>

3. Make the change in the pod configuration.
```
k edit pod webserver
```
<br> 

Change line to:
<br>
`
Image:          nginx:latests
`
<br>
<br>
Save and exit
<br>
<br>

4. Check status of pod and `webserver`.
```
k get pods
```
<br>

```
k get pod webserver
```
